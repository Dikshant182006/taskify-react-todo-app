# 📝 Taskify – Modern Todo App

A clean and responsive Todo application built using React and Tailwind CSS.  
It allows users to manage daily tasks efficiently with a modern UI and smooth user experience.

## ✨ Features

- ➕ Add new todos
- 🗑️ Delete todos
- ✏️ Edit todos
- ✅ Mark as completed
- 🔍 Filter tasks (All / Active / Done)
- 💾 Persistent storage using localStorage
- 📱 Fully responsive design
- 🎨 Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

- React (Hooks)
- Tailwind CSS
- JavaScript (ES6)
- Vite
- LocalStorage

---

## 🧠 What I Learned

- Managing state using `useState`
- Side effects using `useEffect`
- Conditional rendering
- Event handling in React
- Responsive design with Tailwind
- Building clean UI with proper spacing and hierarchy

---

## ⚡ How It Works

- Todos are stored in state
- Data is saved in localStorage using `useEffect`
- Filtering is handled dynamically using conditions
- UI updates automatically on state change
